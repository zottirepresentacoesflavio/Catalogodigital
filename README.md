# Catálogo Zotti — PWA

## Arquivos
- index.html — catálogo completo (atualizar mensalmente)
- sw.js — service worker (não mexer)
- manifest.json — configuração do app (não mexer)
- icon-192.png / icon-512.png — ícones (não mexer)

## Atualização mensal
1. Gere o novo index.html
2. No GitHub, abra o repositório
3. Clique em index.html → botão lápis ou arraste o arquivo novo
4. Clique em Commit changes
5. Pronto — na próxima vez que o vendedor abrir com internet, atualiza automaticamente
